# Стили перетаскивания виджетов
**Статус:** done
**Создан:** 2026-04-14

## Цель
Реализовать визуальное поведение при перетаскивании виджетов по дизайну из видео.

## Шаги
- [x] Source виджет: opacity 0.5, выглядит как серый прямоугольник
- [x] Overlay (летящий): opacity 0.5 + border 2px solid #7A45E5
- [x] Слоты в ряду: 4px вертикальный разделитель, реагирует на курсор по виджету (left/right half-zone)
- [x] Разделитель по центру промежутка: left/right -10px (gap=16px, центр=8px, смещение на half-width линии)
- [x] Между рядами: 4px горизонтальная линия при наведении

## Контекст
- Слоты не должны занимать пространство в layout — только визуальный индикатор
- Разделитель появляется только когда виджет близко к зоне (isOver от dnd-kit)
- Source и overlay оба 0.5 opacity
