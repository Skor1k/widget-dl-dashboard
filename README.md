# Page to Figma

Создавайте React-страницы и автоматически получайте готовые макеты в Figma.

---

## Часть 1. Настройка проекта

Вы скопировали содержимое этой папки в новый проект (Cursor, VS Code и т.д.).
Теперь нужно установить зависимости. Напишите агенту:

> **Установи зависимости проекта и запусти dev-сервер.**

Агент выполнит установку и запустит сервер. В браузере автоматически откроется страница (по умолчанию `localhost:3000`). Если порт 3000 занят, можно попросить агента запустить на другом порту — например: *«Запусти на порту 3001»*.

Вы увидите страницу-шаблон с заголовком, полем ввода и двумя кнопками. Готово — проект работает.

> Если агент говорит что не найден Node.js — скачайте его с [nodejs.org](https://nodejs.org/) (кнопка LTS) и установите. После этого повторите.

---

## Часть 2. Создание страницы из Figma-макета

У вас есть ссылка на макет в Figma и вы хотите получить рабочую страницу. Напишите агенту:

> **Реализуй страницу по этому макету из Figma: `<вставьте ссылку>`**

Агент посмотрит макет, создаст или отредактирует файл в `src/` и соберёт страницу из компонентов дизайн-системы. Результат сразу видно в браузере (если dev-сервер запущен).

### Что можно уточнить

- *«Добавь кнопку "Отправить" после формы»*
- *«Замени выпадающий список на радио-кнопки»*
- *«Сделай два варианта страницы: для новых и существующих пользователей»*

Агент знает все компоненты дизайн-системы и правила их использования — просто описывайте что хотите словами.

---

## Часть 3. Перенос готовой страницы обратно в Figma

Когда страница готова в коде и вы хотите получить Figma-макет автоматически.

### Одноразовая подготовка (делается один раз)

**3.1.** Нужен Figma API токен. Получите его так:

1. Откройте [figma.com](https://figma.com) → кликните на свою аватарку (левый верхний угол) → **Settings**
2. Прокрутите до раздела **Personal access tokens**
3. Нажмите **Generate new token**, дайте ему любое имя, нажмите **Generate**
4. Скопируйте токен (он показывается только один раз!)

**3.2.** Напишите агенту:

> **Создай файл .env из .env.example**

Агент создаст файл `.env`. Затем откройте его сами (он появится в корне проекта) и замените `ТВОЙ-ТОКЕН-ИЗ-ФИГМЫ` на скопированный токен. Не передавайте токен через чат с агентом — это небезопасно.

**3.3.** Установите плагин в Figma Desktop:

1. Если у вас нет Figma Desktop — [скачайте](https://figma.com/downloads/) и установите
2. Напишите агенту: **Собери Figma-плагин** (он выполнит `npm run build:plugin`)
3. В Figma Desktop: верхнее меню → **Plugins** → **Development** → **Import plugin from manifest...**
4. Найдите файл `figma-plugin/manifest.json` в папке вашего проекта → **Open**

### Генерация макета (каждый раз когда нужно)

**Шаг 1.** Напишите агенту:

> **Сгенерируй JSON для Figma из моей страницы src/MyPage.tsx**

Агент создаст файл с описанием вашей страницы в папке `figma-plugin/src/pages/`.

**Шаг 2.** В Figma Desktop откройте нужный файл и запустите плагин:

- Верхнее меню → **Plugins** → **Development** → **Page to Figma**

**Шаг 3.** В открывшемся окне плагина:

1. Вкладка **JSON** уже активна
2. Скопируйте содержимое JSON-файла из `figma-plugin/src/pages/` и вставьте в поле
3. Нажмите **Создать в Figma**

На холсте появится готовый макет из настоящих компонентов дизайн-системы.

## Что писать агенту — шпаргалка

| Что хочу | Что написать агенту |

| Собрать для продакшена | *Сделай production-сборку* |

## Если что-то пошло не так

Просто опишите проблему агенту — он знает про все известные особенности проекта и поможет.

Частые ситуации:

- **Страница не открывается** — скажите агенту: *«Страница не открывается в браузере, помоги»*
- **Ошибки при установке** — скажите: *«При установке зависимостей ошибка»* и покажите текст ошибки
- **Шрифт в Figma не тот** — шрифт YS Text нужно установить в систему. Скажите агенту: *«Шрифт в Figma не работает»* — он объяснит как исправить
- **JSON не генерируется** — скажите: *«Не получается сгенерировать JSON для Figma»*
